# Rishabh Raj — Nawabi Night

Multi-page personal site for Rishabh Raj, Advocate (Lucknow), founding partner of Ink & Equity.

Plain HTML, CSS and JavaScript. No build step and no dependencies except Google Fonts. Open `index.html` or host the folder on any static host (GitHub Pages, Netlify, Vercel).

## Pages
- `index.html`: home, with an animated Lucknow skyline, kites and lantern embers
- `practice.html`: practice areas and how a matter moves
- `lab.html`: legal-tech builds, clause-to-code translator, drafting terminal
- `about.html`: bio, credentials, and a "Prepare a brief" intake that builds a copyable brief
- `arcade.html`: game hub with best scores saved in the browser

## Games (`games/`)
- `case-file.html`: The Mutation Mystery, a detective game about a forged sale deed
- `clause-arcade.html`: match legal terms to their meaning in 60 seconds
- `court-day.html`: move between courtrooms to get six matters heard
- `quiz.html`: ten questions on Indian law and courts

## Shared
- `assets/style.css`: design tokens and components
- `assets/site.js`: page transitions, skyline canvas, reveals, disclaimer bar and game helpers

All game facts are fictional. The site carries a Bar Council of India disclaimer.
